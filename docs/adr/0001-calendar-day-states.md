# 日历状态用底色表达，今天与选中各占一个独立通道

日历格原本只有二元标记（有记录 / 无记录），「全部完成」和「一条没做」长得完全一样。改成三态：无待办、有未完成、全部完成，**用整格底色表达**——24px 的格子里只有整块面积够做三分，小圆点的空心/实心在真实尺寸下分不出来。

代价是底色被状态占满，于是「今天」和「选中日」必须让出填充通道：今天退成数字下方一道短横线，选中日退成 2px 内描边环。这两个信号因此可以叠加（今天且选中 = 短横线 + 环），而选中日那天的状态底色依然可见。

## 考虑过的替代

- **保留选中日的实心玫红块**：最醒目，但会把那一天的底色整个盖掉——恰好是你最常看的一天，也是最需要看出「今天到底做完没有」的一天。
- **把三态做成小圆点的三种形态（无点 / 实心 / 空心）**：不动底色，但 3px 的环在真实尺寸里和实心点糊成一团。
- **全完成用墨色而不是绿**：不引入第三个色相，但「墨色实心」在纸面上读不出「了结」的意思。绿色是唯一一个非玫红的语义色，挑的是与 `--color-soft` 明度相当的淡灰绿，并排放着不会有一块跳出来。
- **部分完成单独一态**（3/5 与 0/5 分开）：24px 里表达不出比例，只会变成「这天的粉深浅不一」。
