# Triage 标签

技能用五个标准 triage 角色说话。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这条 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整规格化，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到某个角色时（例如「打上 AFK-ready 的 triage 标签」），用上表对应的标签字符串。

要换词表，直接改「本仓库标签」这一列。
